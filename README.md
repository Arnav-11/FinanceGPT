# 📈 FinanceGPT

AI-powered stock market analysis platform built with **FastAPI**  and **LSTM-based forecasting** for Indian stock market data.

FinanceGPT provides:
- 📊 Real-time stock insights
- 🤖 AI-driven stock prediction
- 📰 Sentiment analysis from financial news
- 📉 Technical indicators & chart analysis
- ⭐ Watchlist management
- 🔍 Stock comparison tools

---

# 🚀 Features

## 📊 Stock Market Analysis
- Live stock price tracking
- Historical stock data analysis
- Moving averages (MA20 & MA50)
- Candlestick chart support
- Technical indicators

## 🤖 Machine Learning Predictions
- Generalized LSTM model training
- Next-day stock movement prediction
- Backtesting support

## 📰 Sentiment Analysis
- News headline analysis
- Sentiment scoring for stocks
- Combined technical + sentiment insights

## ⭐ Watchlist System
- Add stocks to watchlist
- Remove stocks from watchlist
- Fetch saved watchlist

## 🔍 Comparison Engine
- Compare two stocks side-by-side
- Technical analysis comparison
- Performance overview
